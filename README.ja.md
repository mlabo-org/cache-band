# cache-band

Claude Code の mod。入力欄の上に、プロンプトキャッシュの読み込み率を1行で出します。

```
cache 直近 99% セッション 96% (読 7.6M / 書 307k) │ 全体60分 96% (読 11.3M / 書 404k)
```

- **直近**：最後の1ターン（本体のみ。サブエージェントのターンは含めない）
- **セッション**：このセッションの記録とそのサブエージェントの記録、最初から全部
- **全体60分**：この Mac の Claude Code の記録すべての直近1時間

率は「キャッシュ読み込み ÷ 入力全体（キャッシュなし＋読み込み＋書き込み）」、「書」はキャッシュ作成分です。90%以上は緑、70%以上は黄、それ未満は赤。読めない記録があったときは `*` が付きます。ターンの終わりごとと30秒ごとに更新し、他の mod の帯はその下に残します。

## 必要なもの

`/Applications/Mini System Monitor.app` に、`--claude-cache-json` に対応した [Mini System Monitor](https://github.com/mlabo-org/mini-system-monitor-rs) が入っていること。mod は自分で記録を読みません。mod のファイル読み込みは 4 MiB までで、長い会話の記録はそれを超えるためです。数えるのをモニターに任せることで、帯とモニターの数字も一致します。入っていないときは `cache --` と出ます。

## 設定

`language`：`auto`（Claude Code の言語設定に従う）、`ja`、`en`
